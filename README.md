## 🚀 最近在做什么

### 1. 工业异常检测论文收敛

围绕真实光照变化下的工业图像异常检测开展实验，当前已从方法搜索进入论文收敛阶段。重点关注：

- 冻结视觉 Backbone + 轻量适配
- 正常样本建模与 1-NN 异常评分
- 多类别、多随机种子与外部数据验证
- 光照敏感性诊断与失败案例分析
- 实验协议、统计结果和论文叙事的一致性

相比单纯追求更高指标，我更关注 **结论边界是否清楚、实验是否可复现、证据链是否完整**。

### 2. Life Dashboard Agent

正在把一个个人任务管理网站改造成“**一句话 / 一段语音 → AI 自动理解 → 生成计划 → 用户确认 → 写入系统**”的智能助手。

目前已完成或正在使用的能力包括：

- 语音 / 文本输入与结构化任务规划
- 项目、任务、记录的自动归类与修改建议
- Proposal 预览、继续调整与确认保存
- Node.js + MySQL 数据持久化
- Python AI Backend 与模型 API 接入
- 注册 / 登录 / Session / 用户数据隔离
- 服务器部署、HTTPS 反向代理与多服务联调

目标不是堆很多按钮，而是让复杂业务逻辑藏在后台，把前台交互尽量做简单。
